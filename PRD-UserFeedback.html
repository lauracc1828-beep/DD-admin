一、概述

背景

平台目前没有收集会员意见的渠道，会员对游戏数量、加载速度、活动、充提等方面的不满只能通过客服零散反映，无法汇总分析。本需求在 H5 前台增加反馈入口，会员可选择反馈类型并补充说明；商户在商户后台查看并处理本站点的反馈，总控在总控后台统一配置反馈类型，查看全部站点的反馈及统计。

目标

  1. 以低打扰的方式收集已登录会员的意见，尤其是游戏加载过程中的体验问题。
  2. 商户可按类型、来源、游戏等维度查看反馈，标记处理状态并记录内部备注。
  3. 总控统一维护反馈类型，并按站点、类型、游戏统计反馈分布与处理情况。

需求范围

端位置内容
H5 前台游戏加载页、「我的」页新增两个反馈入口，打开同一个反馈浮层；提交成功页。
商户后台消息管理 › 用户反馈新增菜单，含「反馈列表」「功能设置」两个标签页：查看、处理、导出本站点反馈；开关本站点前台反馈入口。
总控后台站点会员管理 › 会员反馈管理新增菜单，含「反馈统计」「反馈列表」「反馈类型配置」三个标签页：统计与查看全部站点反馈（只读），统一配置反馈类型。

不在本需求范围：后台回复会员、站内信通知会员处理结果、会员查看自己的反馈记录、反馈采纳奖励（前台不显示任何奖励信息）。

名词定义

名词定义
反馈会员在反馈浮层成功提交的一条记录，包含所选反馈类型、补充说明、联系方式及系统自动附带的信息。
反馈类型反馈浮层中供会员多选的选项，由总控后台统一配置，对全部站点生效。
来源入口会员打开反馈浮层的入口，取值「游戏加载页」或「「我的」页」。
处理状态商户对反馈的处理标记，取值「待处理」「已处理」「无需处理」。新提交的反馈为「待处理」。
每日提交上限同一会员每个自然日最多成功提交 3 条反馈。自然日按站点时区划分，00:00 重置。

二、总控后台

2.1 菜单与页面结构

  • 菜单位置：站点会员管理 › 会员反馈管理，排在「会员水位管理」之后。
  • 页面内三个标签页，顺序为：反馈统计 / 反馈列表 / 反馈类型配置。点击菜单默认进入「反馈统计」。
  • 数据范围：全部站点。总控对反馈的处理状态和处理备注只读，处理由各站点在商户后台完成。
  • 面包屑：站点会员管理 / 会员反馈管理。
  • 权限：菜单按「会员反馈管理-查看」控制是否可见；「导出」按钮按「会员反馈管理-导出」控制是否显示；会员账号是否显示完整按「会员反馈管理-查询完整用户名」控制，见 2.6。

2.2 反馈统计

2.2.1 筛选项

字段含义控件必填输入要求 / 说明
站点统计范围内的站点下拉多选（含「全选」）否选项为全部站点名称。默认全部勾选，显示「全部站点」；勾选部分站点时显示「已选 N 个站点」。全部不勾选时按全部站点统计。
统计日期按反馈提交时间统计的时间范围下拉单选是选项：今天 / 近 7 天 / 近 30 天 / 近 60 天 / 近 90 天，默认「近 30 天」。「近 N 天」指含今天在内的 N 个自然日，自然日按总控后台时区划分。
来源入口只统计指定入口提交的反馈下拉单选否选项：全部 / 游戏加载页 / 「我的」页，默认「全部」。
  • 进入页面时按默认条件（全部站点、近 30 天、全部入口）自动查询一次。
  • 修改筛选项后数据不变，点击「查询」后才按新条件统计。
  • 切换到其他标签页再切回时，保留上一次查询的条件和结果。

2.2.2 统计指标

指标口径
反馈总数筛选范围内提交成功的反馈条数。
反馈会员数筛选范围内提交过反馈的会员数，按「站点 + 会员ID」去重。
待处理筛选范围内处理状态为「待处理」的反馈条数，按查询时的当前状态统计。
处理率（已处理 + 无需处理）÷ 反馈总数 × 100%，保留 1 位小数；反馈总数为 0 时显示 0%。

2.2.3 统计表

统计表列规则
按反馈类型反馈类型 / 选择次数 / 占比一条反馈可选多个类型，每选一个类型该类型计 1 次，各类型次数之和可大于反馈总数。占比 = 选择次数 ÷ 反馈总数 × 100%，保留 1 位小数。按选择次数从高到低排列；选择次数为 0 的类型不显示；已停用的类型名称后标注「（已停用）」。
游戏 TOP 10排名 / 游戏 / 厂商 / 反馈数 / 最多的反馈类型只统计来源入口为「游戏加载页」的反馈，按「游戏名称 + 厂商」区分游戏。按反馈数从高到低取前 10 名，反馈数相同时最近一次提交时间晚的在前。「最多的反馈类型」为该游戏反馈中选择次数最多的类型，次数相同时取反馈类型配置中排序靠前的。筛选来源入口为「「我的」页」时该表显示「暂无数据」。
按站点站点名称 / 厅主账号 / 反馈总数 / 反馈会员数 / 待处理 / 已处理 / 无需处理 / 处理率只显示筛选范围内有反馈的站点，按反馈总数从高到低排列。各列口径同 2.2.2。

筛选结果无数据时，指标显示 0，各统计表显示「暂无数据」。

2.3 反馈列表

2.3.1 筛选项

字段含义控件必填输入要求 / 说明
站点按所属站点筛选下拉多选（含「全选」）否同 2.2.1「站点」。
厅主账号按站点所属厅主筛选输入框否精确匹配，去除首尾空格。
提交时间反馈提交时间范围日期范围选择否开始日期 00:00:00 至结束日期 23:59:59；结束日期不可早于开始日期。
会员ID按提交反馈的会员筛选输入框否精确匹配，仅数字。
反馈类型筛选包含该类型的反馈下拉单选否选项：全部 + 反馈类型配置中的全部类型（按排序）；已停用的类型标注「（已停用）」。默认「全部」。
来源入口按打开浮层的入口筛选下拉单选否选项：全部 / 游戏加载页 / 「我的」页，默认「全部」。
处理状态按当前处理状态筛选下拉单选否选项：全部 / 待处理 / 已处理 / 无需处理，默认「全部」。
游戏名称按游戏加载页来源的游戏筛选输入框否模糊匹配，不区分大小写。
  • 「查询」：按当前筛选项查询；「重置」：筛选项恢复默认并重新查询。
  • 「导出」：导出当前筛选条件下的全部反馈，导出列与列表列一致（不含「操作」列），另加处理备注（最新一条）；图片列导出图片链接，多张以换行分隔。会员账号与列表显示一致：有「查询完整用户名」权限导出完整账号，否则导出脱敏账号。导出为异步任务，按总控后台现有导出方式下载。仅具备「会员反馈管理-导出」权限的账号显示「导出」按钮，无权限时不显示。
  • 列表上方说明：「总控只读：可查看各站点的反馈及处理情况，不可修改处理状态和备注。」

区块字段

2.5.1 列表

列说明

2.5.2 新增 / 编辑类型

弹窗标题为「新增类型」或「编辑类型」，编辑时回填当前值。按钮「取消」「确定」。

字段含义控件必填输入要求错误提示

2.5.3 启用与停用规则

  1. 启用的类型最多 10 个：已有 10 个启用时，再启用（列表开关或弹窗）提示「最多启用 10 个反馈类型」，不生效。
  2. 至少保留 1 个启用的类型：仅剩 1 个启用时，停用该类型提示「至少保留 1 个启用的反馈类型」，不生效。
  3. 列表开关切换成功后提示「已启用」或「已停用」。
  4. 停用后前台不再显示该类型；已提交的反馈保留该类型，后台显示时标注「（已停用）」，筛选与统计中仍可选到。
  5. 编辑类型名称后，后台所有反馈（含历史）显示新名称。
  6. 配置保存后对全部站点生效，前台在会员下一次打开反馈浮层时加载最新的类型。

2.6 权限配置与会员账号脱敏

2.6.1 权限点

在总控后台「系统角色管理」的角色权限配置中，为「会员反馈管理」新增三个权限点：

权限点控制范围默认
会员反馈管理-查看菜单「站点会员管理 › 会员反馈管理」是否可见，以及能否使用页面内的查看与配置功能（反馈统计、反馈列表与详情、反馈类型配置），不含导出。未授权的角色不显示该菜单。仅有此权限时，不显示「导出」按钮，会员账号显示为脱敏账号。现有角色默认不具备，由管理员在角色配置中勾选授权。
会员反馈管理-导出反馈列表的「导出」按钮是否显示及能否导出。未授权时不显示「导出」按钮。导出文件中的会员账号是否完整，仍按「查询完整用户名」权限决定。需同时具备「会员反馈管理-查看」才生效。现有角色默认不具备，由管理员在角色配置中勾选授权。
会员反馈管理-查询完整用户名是否显示会员的完整账号。授权后，反馈列表、反馈详情与导出文件中的会员账号直接显示完整账号；未授权时一律显示脱敏账号。需同时具备「会员反馈管理-查看」才生效。现有角色默认不具备，由管理员在角色配置中勾选授权。
  • 角色权限变更后，该角色下的账号刷新页面即按新权限显示。
  • 三个权限点只作用于总控后台；商户后台「消息管理 › 用户反馈」的会员账号显示不变。

五、交互逻辑

5.1 提交校验顺序

点击「提交」后按以下顺序校验，任一项不通过即停止，浮层保持打开、已填内容保留：

顺序校验不通过时
1至少选择 1 个反馈类型「提交」按钮置灰，无法点击。
2联系方式为空或格式正确（前端校验）输入框标红，下方提示「请输入正确的 WhatsApp 号码或邮箱」。
3当天成功提交未达 3 条（服务端校验）提示「今天的反馈次数已达上限，请明天再来」。

全部通过后保存反馈，显示提交成功页（4.5），该会员当天已提交条数加 1。

5.2 每日提交上限

  1. 同一会员每个自然日最多成功提交 3 条，按站点时区 00:00 重置；提交失败、被拦截的不计数。
  2. 上限对两个入口合并计算。
  3. 达到上限后入口不隐藏，点击「提交」时提示「今天的反馈次数已达上限，请明天再来」。

5.3 上传图片

  1. 非必填，最多 3 张；格式 JPG、PNG；单张不超过 5MB。
  2. 点击「添加图片」调起手机系统相册，可多选。首次使用时由系统请求相册访问权限；会员拒绝授权时不添加图片，浮层其他内容不受影响。
  3. 选择后逐张校验，不符合的图片不添加，其余正常添加：
    • 格式不是 JPG、PNG：提示「仅支持 JPG、PNG 格式图片」；
    • 单张超过 5MB：提示「图片大小不得超过 5MB」；
    • 选择张数超过剩余可上传张数：按选择顺序添加至 3 张为止，提示「最多上传 3 张图片」。
  4. 图片添加后立即上传，缩略图上显示「上传中」；上传失败的缩略图显示「上传失败」，会员可删除后重新添加。
  5. 有图片处于「上传中」时，「提交」按钮置灰（不可点击），全部上传结束后恢复。提交时只附带上传成功的图片。
  6. 关闭浮层后已选图片清空，不保留。

九、边界与异常

场景处理
未登录会员（游客）进入游戏加载页或「我的」页不显示反馈入口。
商户关闭「意见反馈功能」本站点两个入口均不显示；已提交的反馈保留，后台可正常查看和处理。
会员已打开浮层，商户此时关闭功能开关已打开的浮层仍可提交，提交正常保存；关闭浮层后入口不再显示。
浮层打开期间游戏加载完成浮层保持打开，已填内容保留，标题下方加载状态变为「✓ 游戏已加载完成，可随时返回游戏」；加载页与入口文字链消失，游戏在浮层下方显示；关闭浮层或点击「返回游戏」后进入游戏。
会员当天已提交 3 条后再次提交提示「今天的反馈次数已达上限，请明天再来」，浮层保持打开，已填内容保留。
会员在多个设备或两个入口同时提交每日上限由服务端按会员统一计数，第 4 条起被拦截。
提交时登录已过期按《全站弹窗调度机制 PRD》4.2 节「登录已过期」处理，本次反馈不保存。
会员已选的类型在提交前被总控停用提交正常保存所选类型，后台显示时标注「（已停用）」。
补充说明只输入空格视为未填写，后台显示「-」。
联系方式填写「+55 (11) 98765-4321」去除空格和符号后为 13 位数字，格式正确，按原样保存。
已选 2 张图片，再从相册选 3 张只添加所选的第 1 张，提示「最多上传 3 张图片」。
图片上传失败缩略图显示「上传失败」；会员可删除后重新添加，或直接提交（只附带上传成功的图片）。
会员拒绝相册访问权限不添加图片，其他内容可正常填写和提交。
连续点击「提交」请求返回前按钮置灰，只提交一次。
总控已启用 10 个类型时再启用提示「最多启用 10 个反馈类型」，不生效。
总控停用最后 1 个启用的类型提示「至少保留 1 个启用的反馈类型」，不生效。
总控修改类型名称前台下次打开浮层显示新名称；后台全部反馈（含历史）显示新名称。
商户未修改状态也未填备注就保存提示「处理状态和备注均未修改」，不保存、不生成处理记录。
商户将「已处理」改回「待处理」允许，生成一条处理记录，显示「已处理 → 待处理」。
总控统计页修改筛选项未点「查询」统计数据保持上一次查询结果。
统计范围内没有反馈指标显示 0，处理率显示 0%，各统计表显示「暂无数据」。
