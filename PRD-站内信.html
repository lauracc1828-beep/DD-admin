站内信 · 信件内容富文本化 PRD

版本：v1.0作者：Laura更新日期：2026-09-12

本需求针对后台「消息管理 → 站内信」页。核心变更：将「站内信发送」表单中的信件内容由纯文本框升级为富文本编辑器，其形态、工具栏与「公告消息」模块的富文本编辑器保持一致，并额外提供「插入 / 编辑链接」功能——运营可在信件正文中插入可点击的超链接。

一、背景与目标

现有站内信「信件内容」为纯文本输入框，无法排版、无法插入图片与链接，运营在发送带活动引导的站内信时只能贴出裸地址、无法做成可点击链接，体验与「公告消息」不一致。

本次目标：

  • 信件内容富文本化：信件内容改为富文本编辑器，能力与公告消息（详见《公告消息 PRD》）的富文本编辑器一致，支持字体、加粗、斜体、下划线、对齐、图片上传等。
  • 新增链接功能：富文本工具栏的链接按钮可真实使用，点击弹出「插入 / 编辑链接」弹框，保存后在正文中生成可点击链接。
  • 公告侧同步：为保持一致，公告模块（弹窗公告、公告消息）富文本工具栏的链接按钮同步启用为真实可用的「插入 / 编辑链接」功能。
站内信页含「站内信发送」与「发送记录」两个 Tab。本期仅交付「站内信发送」页；「发送记录」Tab 保留入口但其页面非本次需求范围，后续需求另行实现（草稿「继续」投递、发送状态流转与记录列表等均在该 Tab）。

二、后台 —「站内信发送」表单

菜单位置：消息管理 → 站内信。表单沿用现有站内信页样式与字段，仅将「信件内容」控件升级为富文本编辑器。字段自上而下如下：

字段含义控件必填输入要求 / 逻辑说明
地区发送作用的地区。下拉否按地区维度隔离，如「巴西站-测试」。
商户发送作用的商户。下拉否按商户维度隔离，如「888」。
发送类型选择投递对象的方式。单选是「会员ID」/「会员层级」二选一，切换后下方对象输入区联动。
会员ID按 ID 精准投递的会员清单。多行文本 + 批量导入是（会员ID时）仅发送类型=会员ID 时显示。多个 ID 用英文逗号分隔；「批量导入」支持通过文件导入 ID 清单。
会员层级按层级批量投递的范围。多选是（会员层级时）仅发送类型=会员层级 时显示。提供「全部」及各会员层级（选项取自会员层级配置），勾选「全部」联动全选。
标题类型信件标题的呈现形态。单选是「文字标题」/「图片标题」，切换后标题字段联动显示。
信件标题文字型标题文本。输入框是（文字标题时）仅标题类型=文字标题 时显示；为空不可保存，提示「请输入信件标题」。
标题图片图片型标题图。上传是（图片标题时）仅标题类型=图片标题 时显示；支持 JPG/PNG/SVG；未上传不可保存，提示「请上传标题图片」。
信件内容信件正文（本次升级项）。富文本编辑器是见第三节。标签右侧提供「前端展示预览」按钮，可预览前台展示效果；为空不可保存，提示「请输入信件内容」。
信件署名信件落款署名。输入框否展示于正文末尾的署名文本。
发送方式信件的投递时机。单选是「立即发送」/「定时发送」。选「定时发送」时展开「发送时间」。
发送时间定时发送的时间点。日期时间选择是（定时时）仅发送方式=定时发送 时显示。

时限说明（页面常驻）：站内信发送时限为 24 小时，超时将无法发送或发送失败。立即发送：保存为草稿后，在发送记录点「继续」投递。

底部操作：「取消」（重置表单）、「保存」（校验后保存）、「预览」（前端展示预览）。

三、信件内容 · 富文本编辑器

信件内容编辑器与公告消息的富文本编辑器形态与工具栏一致，包括：菜单区（文件 / 编辑 / 插入 / 视图 / 格式）、字号、查找、加粗 / 斜体 / 下划线 / 删除线、对齐与缩进、引用、撤销 / 重做、插入链接、图片上传等；编辑器右上角提供「图片上传」，并标注图片规格 640x260/jpg/.gif/.png；底部显示字数统计。

与公告的差异：仅图片规格提示文案不同（站内信为 640x260，公告弹窗为 700x284、公告消息为 760x任意高度）；其余工具栏与交互一致。

3.1 插入 / 编辑链接（本次新增功能）

点击工具栏的链接按钮弹出「插入 / 编辑链接」弹框。若插入前在编辑器中选中了文字，该文字自动带入「显示文字」；若光标位于已有链接上，则进入编辑态，回填该链接的地址、显示文字与打开位置。

字段含义控件必填输入要求 / 逻辑说明
地址链接跳转的目标 URL。输入框是为空不可保存，提示「请输入链接地址」；未带协议时系统自动补全 http://。
显示文字正文中呈现的链接文案。输入框否与地址联动：当显示文字未被手动输入 / 修改过时，输入或修改「地址」会逐字同步填入显示文字；一旦用户在显示文字框内手动输入或修改，则停止同步，之后修改地址不再更新显示文字。打开弹框时若显示文字已有内容（选中文字带入 / 编辑既有链接回填），视为已设置，地址不再覆盖。保存时若仍为空，默认取「地址」作为显示文字。
链接打开位置…点击链接的打开方式。下拉是「在新窗口打开」（target=_blank，默认）/「在当前窗口打开」（target=_self）。

弹框操作：「取消」关闭不生效；「保存」后——新增时在光标处（或替换选中文字）插入可点击链接，编辑时按新值更新原链接——并提示「链接已插入」，同步刷新字数统计。

四、保存校验规则

场景校验规则错误 / 结果提示
站内信发送 · 保存文字标题时，信件标题不可为空请输入信件标题
站内信发送 · 保存图片标题时，标题图片必须上传请上传标题图片
站内信发送 · 保存信件内容不可为空请输入信件内容

站内信发送 · 保存（定时发送）校验通过已保存，定时发送
信件内容 · 前端展示预览内容为空请先输入信件内容
插入链接 · 保存地址不可为空请输入链接地址
插入链接 · 保存校验通过链接已插入

所有提示以 toast 形式呈现；点击「保存」时按字段从上到下校验，仅提示第一个未通过项并阻断提交。

六、公告侧同步说明

为保持富文本能力一致，本次将公告模块富文本工具栏的链接按钮同步启用为真实可用的「插入 / 编辑链接」功能，弹框字段与交互与站内信一致，覆盖：

  • 弹窗公告（新增 / 编辑弹窗公告 · 弹窗内容编辑器）。
  • 公告消息（公告发放 · 公告内容编辑器）。

公告其余字段与逻辑维持现状，详见《公告消息 PRD》，不在本次范围内变更。

七、边界与异常

  • 发送类型切换：由「会员ID」切至「会员层级」时隐藏 ID 输入区、展示层级多选，反之亦然；两者互斥，仅提交当前所选方式的数据。
  • 标题类型切换：「文字标题」与「图片标题」互斥展示，仅校验并提交当前所选。
  • 链接地址协议：用户未输入协议时自动补全 http://；已带 http(s)://、//、# 或其他协议前缀的地址保持原样。
  • 编辑已有链接：光标落于链接文字上再点「插入链接」进入编辑态，回填并按新值更新，不新增重复链接。
  • 发送时限：站内信发送时限 24 小时，超时无法发送或发送失败；立即发送先存为草稿，需在发送记录中「继续」完成投递。
  • 发送记录（本期不做）：草稿的「继续」投递、发送状态流转与记录列表属「发送记录」Tab，后续需求实现。
