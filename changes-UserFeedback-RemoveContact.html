用户反馈收集 · 本次改动说明
去掉会员联系方式（WhatsApp / 邮箱）收集
对应 PRD：v1.5 → v1.6更新日期：2026-11-18作者：Laura

一、改动概览

反馈浮层不再收集会员的联系方式，H5 前台、商户后台、总控后台同步去掉联系方式相关的输入、校验、展示、筛选与导出。完整需求以《用户反馈收集 PRD》v1.6 为准，本文只说明相对 v1.5 的改动点。

#改动点类型涉及章节
1H5 反馈浮层去掉「联系方式（选填）」输入项及格式校验删除4.4、5.1、六、八、九
2商户后台反馈列表去掉「联系方式」筛选项与列，详情去掉联系方式删除3.2.1、3.2.2、3.3
3总控后台反馈列表去掉「联系方式」列，详情去掉联系方式删除2.3.2、2.4、2.6.2
4反馈数据不再包含联系方式字段（含导出）删除一（名词定义）、七

二、逐项说明

改动 1 · H5 反馈浮层删除

项目v1.6 规则
浮层内容自上而下为：标题栏 / 问题 / 反馈类型 / 补充说明（选填）/ 上传图片（选填）/ 提交按钮。去掉「联系方式（选填）」标题与「WhatsApp 或邮箱」输入框。
提交校验顺序① 至少选择 1 个反馈类型 → ② 当天成功提交未达 3 条（服务端校验）→ ③ 请求成功。去掉原第 2 步「联系方式为空或格式正确」及其错误提示。
下线的文案 联系方式（选填）／Contato (opcional)
WhatsApp 或邮箱／WhatsApp ou e-mail
请输入正确的 WhatsApp 号码或邮箱／Por favor, insira um WhatsApp ou e-mail válido

改动 2 · 商户后台「消息管理 › 用户反馈」删除

位置v1.6 规则
筛选项提交时间 / 会员查询 / 反馈类型 / 来源入口 / 处理状态 / 游戏名称。去掉「联系方式（全部 / 有 / 无）」。
列表列反馈ID / 提交时间 / 会员ID / 会员账号 / VIP等级 / 反馈类型 / 补充说明 / 图片 / 来源入口 / 游戏 / 处理状态 / 处理人 / 处理时间 / 操作。去掉「联系方式」列。
反馈详情「反馈内容」区块为：反馈ID、提交时间、反馈类型、补充说明、图片。去掉联系方式。
导出导出列与列表列一致，不含联系方式。

改动 3 · 总控后台「站点会员管理 › 会员反馈管理」删除

位置v1.6 规则
反馈列表列站点名称 / 厅主账号 / 反馈ID / 提交时间 / 会员ID / 会员账号 / VIP等级 / 反馈类型 / 补充说明 / 图片 / 来源入口 / 游戏 / 处理状态 / 处理人 / 处理时间 / 操作。去掉「联系方式」列。
反馈详情「反馈内容」区块为：站点名称、厅主账号、反馈ID、提交时间、反馈类型、补充说明、图片、处理状态。去掉联系方式。
导出导出列与列表列一致，不含联系方式。

改动 4 · 反馈数据删除

项目v1.6 规则
会员填写字段反馈类型、补充说明、图片。提交接口不再接收、不再保存联系方式。
其他字段系统记录、自动附带、处理信息各字段不变。
