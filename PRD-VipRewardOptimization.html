一、需求背景与范围

VIP管理（《【站点】vip管理（对齐熊猫）》）上线后，对照熊猫的规则发现几处发放、领取和后台展示上的差异。经讨论，本需求只处理以下两个优化点，其余 VIP 规则保持现状。

本次改动范围

序号优化点涉及端改动内容章节
1受众用户1 · 晋级奖励服务端、客户端领取规则为「受众用户1」时，领取晋级奖励也要满足受众条件，不满足的弹充值引导。第三章
2作废奖励的后台显示服务端、后台「等级奖励记录」增加「已作废」状态和筛选项，备注列写明作废原因；上线时刷新存量记录。第四章

不在本需求范围：日/周/月奖励所需流水为 0 时的派发规则，见《【站点】VIP奖励机制优化》；奖励生成规则、奖励金额、稽核倍数与限定平台、保级规则、周期中途晋级的处理、作废时间点、「回收作废」与「受众用户2」的领取规则、前台各页签与弹窗样式，均沿用现有 VIP管理 PRD 与当前实现，本需求不做改动。

二、改动前后对比

项改动前改动后
受众用户1 · 领取晋级奖励不校验受众条件，直接可领。要满足受众条件；不满足的弹充值引导弹窗，充值后才能领。
受众用户1 · 「一键领取」「领取全部晋级奖励」晋级奖励部分不校验受众条件。与日/周/月奖一样校验受众条件。
「等级奖励记录」状态只有「未领取」「已领取」；已作废的记录显示为「未领取」。增加「已作废」；作废的记录显示「已作废」，备注列写明作废原因。
「等级奖励记录」状态筛选未领取 / 已领取未领取 / 已领取 / 已作废

三、优化点 1：受众用户1 下领取晋级奖励校验受众条件

规则

  • 适用条件：后台「领取规则」选择「受众用户1」（跨天/跨周/跨月未领取奖励回收作废，N 天内充值）。
  • 受众条件：与日/周/月奖相同，即近 N 天（不含当天）或当天有任意金额的成功充值。N 取后台「N天内充值」的配置值。
  • 校验时机：会员点击领取时由服务端校验，前台不提前置灰。按钮的「未达标 / 已达标」显示规则不变：有未领取的晋级奖励时按钮高亮可点。
  • 满足条件：发放所有未领取的晋级奖励，弹领取成功弹窗，展示到账金额。
  • 不满足条件：不发放，弹充值引导弹窗。文案「Receba uma recompensa exclusiva após efetuar qualquer depósito」（完成任意金额充值后，即可获得专属奖励），按钮「Depósito」跳转充值页、「Cancelar」关闭弹窗。晋级奖励保留为未领取，充值成功后可再领。
  • 晋级奖励不作废：晋级奖励没有周期，不因跨天/跨周/跨月作废；本优化只增加领取校验，不改变晋级奖励的累加和保级相关的作废规则。

涉及的领取入口

入口受众用户1 下的处理
「Bônus」页签底部「Reclamar Recompensa de Upgrade」按上述规则校验。满足则一次领取全部未领取的晋级奖励；不满足则弹充值引导弹窗，一笔都不发。
顶部「Coletar Tudo」（一键领取）晋级奖励与日/周/月奖使用同一受众条件。满足则一并领取全部可领奖励；不满足则弹充值引导弹窗，一笔都不发。

领取规则为「回收作废」「受众用户2」时，晋级奖励领取不校验受众条件，保持现状。

四、优化点 2：等级奖励记录增加「已作废」状态

页面路径：福利中心 ＞ VIP管理 ＞ 等级奖励记录。

4.1 状态定义

状态含义
未领取已生成、尚未领取，且还没到作废时间，会员仍可领取。
已领取会员已领取，或「受众用户2」到期时系统自动发放。
已作废系统已作废，会员不能再领取。作废后状态不再变化。

变为「已作废」的场景与备注

场景作废时刻备注列写入
日/周/月奖到期未领取（领取规则为回收作废、受众用户1、受众用户2）到达该奖励的作废时间点（沿用现有规则）过期作废
晋级奖励未领取，保级关闭时会员降级降级时降级作废

备注列原本已有内容的，作废原因追加在原内容后，用「；」分隔。

4.2 列表与筛选

位置改动
筛选区「状态」下拉单选，选项改为：全部（默认）/ 未领取 / 已领取 / 已作废。
列表「状态」列按 4.1 展示三种状态；「已作废」用灰色文字展示。
列表「领取时间」列状态为「已作废」时展示「-」。
列表「备注」列状态为「已作废」时展示作废原因（过期作废 / 降级作废）。
「导出」导出文件的状态、备注与列表一致，按当前筛选条件导出。

列表其余列（手机号、订单号、福利金额、福利类型、稽核倍数、订单生成时间、账号类型、会员等级、上级代理）和其余筛选项不变。

4.3 上线时的存量数据处理

  • 上线时，把已被系统作废、列表中仍显示「未领取」的历史记录统一改为「已作废」，备注按 4.1 的场景写入「过期作废」或「降级作废」。
  • 仍在有效期内的「未领取」记录、所有「已领取」记录不变。
  • 存量处理只改展示状态，不改变奖励金额，也不影响会员的领取结果。

五、边界与异常处理

场景处理方式
受众用户1 下，会员在充值引导弹窗点「Depósito」但没有完成充值回到 VIP 页面后晋级奖励仍为未领取，再次点击仍弹充值引导弹窗。
受众用户1 下，会员当天充值成功后立即领取当天有充值即满足受众条件，可正常领取。
运营把领取规则从受众用户1 改为其他规则改动保存后，会员再领取晋级奖励时按新规则处理，不再校验受众条件。
前台未刷新、会员点击已作废的奖励服务端拒绝发放，前台提示领取失败并刷新奖励列表。
同一会员并发点击领取服务端按奖励记录加锁，同一记录只发放一次；作废与领取同时发生时，先完成的生效。

六、验收标准

  • 领取规则为受众用户1、会员不满足 N 天内充值时，点击「Reclamar Recompensa de Upgrade」弹充值引导弹窗，晋级奖励不发放。
  • 同一场景下点击「Coletar Tudo」弹充值引导弹窗，晋级奖励和日/周/月奖都不发放。
  • 满足受众条件（含当天充值）后，以上两个入口都能正常领取，弹领取成功弹窗并展示合计到账金额。
  • 领取规则为回收作废、受众用户2 时，晋级奖励领取不校验受众条件。
  • 直接调用领取接口时，服务端同样按受众条件校验。
  • 日/周/月奖过期后，「等级奖励记录」中状态为「已作废」，备注「过期作废」，领取时间「-」。
  • 保级关闭、会员降级后，未领取的晋级奖励状态为「已作废」，备注「降级作废」。
  • 状态筛选包含「已作废」，筛选和导出结果正确。
  • 上线后，历史上已作废的记录显示为「已作废」，有效期内的未领取记录不受影响。
