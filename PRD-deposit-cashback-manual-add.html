一、需求背景与范围

商户后台「商户财务配置 — 充提返现设置」包含「充值返现」「提款返现」两个标签页。现状下两者的列表逻辑不一致：「充值返现」自动同步支付方式管理中的全部存款方式，只能编辑、不能新增或删除；「提款返现」由运营手动新增需要返现的提款通道，并支持删除。

本需求将「充值返现」标签页的列表逻辑改为与「提款返现」一致：列表只展示手动新增的存款方式，通过「新增」按钮逐条添加，并支持删除。运营只需维护实际要做返现的存款方式，列表不再堆积大量未配置的行。

四、后台改动说明

4.1 列表页

  • 数据来源：列表只展示已手动添加的存款方式，不再自动同步支付方式管理中的全部存款方式。未添加的存款方式不产生充值返现。
  • 「新增」按钮：位于列表区右上角（列工具组左侧）。点击唤起「会员存款返现设置」新增弹窗（4.3）。全部存款方式均已添加时，按钮置灰（不可点击），悬停提示「全部存款方式均已添加」；删除任一行后恢复可点击。
  • 与存款方式启停无关：在支付方式管理中为「禁用」的存款方式同样可添加与编辑，便于提前配置；前台不展示该存款方式，故不会产生返现。
  • 默认排序：按最近操作时间倒序，新增的行位于首行。
  • 列表为空：未添加任何存款方式时，列表展示「暂无数据」。

列字段中发生变化的项如下，未列出的列（返现方式、状态）不变：

列改动后的说明
存款方式新增时选定的存款方式名称，与支付方式管理中的配置同名。添加后不可修改。
返现百分比例（%）去除末尾无意义的 0 后展示。取消「展示为 0 表示尚未配置」的说明，列表中不再出现 0。
每日最高优惠（元）去除末尾无意义的 0 后展示。取消「展示为 0 表示尚未配置」的说明。
最近操作时间该行最后一次新增、保存配置或切换状态的时间，格式 YYYY-MM-DD HH:mm:ss (UTC-3)。取消「从未操作过时展示为空」的说明。
操作人最近一次操作的后台账号。取消「从未操作过时展示为空」的说明。
操作「编辑」按钮唤起「会员存款返现设置」编辑弹窗（4.3）；「删除」按钮位于「编辑」右侧，删除该行配置（4.4）。

4.2 筛选区：存款方式

字段控件必填说明与选项
存款方式下拉单选否选项为支付方式管理中的全部存款方式（不区分状态，顺序与该页一致），不与列表联动：未添加到列表的存款方式同样列出，选中后查询结果为「暂无数据」。默认空（全部）。

筛选区其余字段（最后操作时间、操作人）与「查询」「重置」按钮不变。

4.3 新增与编辑弹窗：会员存款返现设置

新增与编辑共用同一弹窗，标题均为「会员存款返现设置」，分「基本信息」与「返现设置」两组，底部为「保存」「重置」。两种模式的差异如下：

项新增（点击「新增」按钮）编辑（点击行内「编辑」）
存款方式下拉单选，必填，默认未选纯文本只读，不可修改
返现设置三项返现百分比、每日最高优惠为空；提现稽核倍数默认填入 0回填该行已保存值
「重置」清空全部输入，存款方式回到未选还原为本次打开弹窗时的已保存值
保存后弹窗关闭，列表新增一行并置于首行，状态为关闭；轻提示「新增成功」弹窗关闭，更新该行；轻提示「保存成功」

基本信息 — 存款方式

字段控件必填说明与选项
* 存款方式新增：下拉单选
编辑：纯文本		是含义：本条返现配置适用的存款方式。
选项来源：支付方式管理中的全部存款方式，不区分启用 / 禁用状态，顺序与该页一致；下拉占位为「请选择存款方式」。
已添加的存款方式：在下拉中置灰（不可选）并标注「（已添加）」，保证同一存款方式在列表中只存在一行；删除后恢复可选。
校验：未选择即点击「保存」时，在字段下方标红提示「请选择存款方式」，不提交。
编辑时：只读展示，不可修改；如需更换存款方式，删除后重新新增。

返现设置 — 提现稽核倍数

字段控件必填说明与选项
* 提现稽核倍数数字输入是含义：返现金额需完成的有效投注倍数，同时作为前台奖励规则气泡中「提现流水要求」的倍数取值来源。
默认值：新增时默认填入 0；编辑时回填该行已保存值。
输入要求：只能填写 0 或正整数，不设上限；输入框只能输入数字，小数点、负号等字符无法输入，粘贴时自动过滤；失焦时去掉前导 0（如 05 → 5）；占位为「请输入」。为 0 时该笔赠送金额不参与提现流水稽核计算，发放时不追加有效投注要求。
校验：清空后失焦或点击「保存」，输入框标红，下方提示「请输入提现稽核倍数」，不提交。

4.4 删除

项说明
入口列表「操作」列「删除」按钮，位于「编辑」右侧。不论状态开启或关闭均可删除。
二次确认点击后弹出确认框：标题「删除确认」，正文「确认删除「{存款方式}」的充值返现配置？删除后该存款方式不再发放充值返现，已发放的返现不受影响。」，按钮「确定」「取消」。点击「确定」后删除该行，轻提示「删除成功」；点击「取消」或右上角关闭，不做任何改动。
删除后的影响即时生效：此后支付成功的该存款方式订单不再发放返现（以支付成功回调时是否存在配置为准）；已发放的返现不回收、已追加的提现流水要求不撤销；前台该渠道的赠送角标、快捷档位比例角标与「含赠送」副行随之不展示。
重新添加删除后该存款方式在新增下拉中恢复可选，可重新添加，新增后状态仍默认关闭。同一自然日（UTC-3）内删除后又重新添加并开启的，会员当日在该存款方式的已发放累计值 S 延续计算，不因删除而清零。

4.5 状态与生效判定

  • 新增后默认关闭：新增成功的行状态为关闭，需运营在列表中手动开启后才生效，避免配置未核对即对会员生效。状态开关的切换方式不变（行内点击即生效，不弹二次确认）。
  • 生效判定：返现是否发放，取决于「该存款方式已添加」与「状态开启」同时成立。任一不成立视同无返现：不计算、不发放、不产生账变，前台不展示赠送角标、快捷档位比例角标与「含赠送」副行。
  • 原「返现百分比 > 0」条件取消：新增与编辑时返现百分比均必填且 ≥ 0.001，已添加的行不会出现返现百分比为 0 的情况。

五、上线时的存量数据处理

上线前的行上线后的处理
返现百分比 > 0视为已添加，保留在列表中；返现百分比、每日最高优惠、提现稽核倍数、状态、最近操作时间与操作人均保持不变。
返现百分比为 0（从未配置过）不保留，不在列表中展示；该存款方式在新增下拉中可选，需要时通过「新增」添加。

存量数据处理不改变任何已生效的返现：上线前状态开启且返现百分比 > 0 的存款方式，上线后仍为已添加且开启，返现照常发放。

六、边界与异常处理

场景处理方式
两名管理员同时新增同一存款方式先提交者成功；后提交者保存时提示「该存款方式已添加」，弹窗保持打开。
全部存款方式均已添加「新增」按钮置灰（不可点击），悬停提示「全部存款方式均已添加」；删除任一行后恢复可点击。
删除正在生效的存款方式即时停止发放；删除前已支付成功的订单已按规则发放，不回收。删除时尚未支付成功的订单，回调时已无配置，不发放。
新接入存款方式不自动加入列表，仅出现在新增下拉中，需手动添加并开启后才产生返现。
存款方式在支付方式管理中被禁用已添加的行保留，可查看、编辑与删除；该存款方式在新增下拉中仍可选。前台不再展示该存款方式，会员无法新发起充值。禁用前已提交、禁用后才支付成功的订单，只要回调时该存款方式的返现配置存在且开启，照常发放。
存款方式从支付方式管理中移除新增下拉与筛选下拉中不再出现该存款方式；已添加的行保留并可删除，历史账变记录保留可查。移除前已提交、移除后才支付成功的订单，规则同上。

七、权限与操作留痕

  • 权限归属：「新增」与「删除」均归属「充值返现」标签页的编辑权限，不新增权限点。仅具备查看权限时，「新增」「编辑」「删除」按钮与状态开关置灰（不可点击）。
  • 操作留痕：新增与删除行为记入后台操作日志，记录操作账号、时间（UTC-3）与存款方式；新增记录完整的初始配置值，删除记录删除前的完整配置值。新增同时刷新该行的「最近操作时间」「操作人」两列。
