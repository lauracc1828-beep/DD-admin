一、背景

活动配置的累计有效投注可以限定平台。运营想查某个下级为什么没有计入有效下级，目前查不到：推广统计只有注册信息，没有达标数据；奖励报表只记录领过奖的数据。

「存款&流水奖励报表」是领奖记录，一次领奖一条。「每次领取推广返佣后清除奖励」的开、关模式切换会影响报表里的记录，所以报表保持不变，下级的达标数据放到「推广统计」里展示。

二、修改点

1. 推广统计

列表仍是一个下级一条，列出所有下级，包括无效下级。新增以下字段，除「备注」放在最后一列外，其余字段放在「注册IP」前面：

字段顺序：序号、推广者ID、推广者账号、受邀者ID、受邀者账号、注册时间、累计充值金额、累计有效投注、是否有效会员、有效会员生效时间、注册IP、注册终端、备注。

序号新增字段说明
1累计充值金额有效会员：统计至有效会员生效时间，生效后不再更新。
无效会员：统计最新充值金额。
触发同注册IP / 同注册设备上限的会员：不统计，显示「-」。
2累计有效投注有效会员：统计至有效会员生效时间，生效后不再更新。
无效会员：按最新配置的限定平台，统计最新投注金额。
触发同注册IP / 同注册设备上限的会员：不统计，显示「-」。
3是否有效会员是 / 否。
4有效会员生效时间下级转为有效的时间；无效下级显示「-」。
5备注说明无效原因，规则见下方第 2 点。
  • 筛选项增加「是否有效会员」：是 / 否。
  • 列表上方增加备注：
活动配置修改后，已生效的有效下级不受影响；原本无效的下级如满足最新配置条件，将自动转为有效。有效会员的充值、投注统计至生效时间；无效会员按最新配置统计。

2. 无效会员备注

无效会员有两种情况：

序号无效情况备注列展示
1累计充值 / 累计有效投注未达标「-」。原因可直接从累计充值金额、累计有效投注两列看出。满足最新配置条件后可自动转为有效。
2触发同注册IP上限 / 同注册设备上限读取活动配置「统计限制」的配置值展示原因：
超过同注册IP上限：「超过同注册IP上限（N）」
超过同注册设备上限：「超过同注册设备上限（N）」
两项都触发时同时展示，用「；」分隔。N 为触发时配置的上限值。
  • 触发判定按全站、按注册顺序计数：全站同注册IP（或同注册设备）的会员中（不区分推广者），前 N 个注册的下级正常判定，从第 N+1 个注册的下级开始触发上限。N 为当时配置的上限值。
  • 触发同注册IP / 同注册设备上限的下级永久无效：无论充值、投注是否达标，之后修改活动配置（包括调高上限），都不会再转为有效。触发后也不再统计其充值、投注，累计充值金额、累计有效投注显示「-」。
  • 上限配置为 0 表示不限制，不会因此产生无效会员。
  • 有效会员备注显示「-」。

3. 活动配置修改规则

  • 活动配置修改，不影响已生效下级的状态。
  • 原本未生效的下级，保存配置后立即按新配置重新判定，充值、投注达标，则自动变为生效；之后下级充值、投注变化时持续判定。生效时间记为转为生效的时间。
  • 触发同注册IP / 同注册设备上限的下级不参与重新判定，永久无效。

4. 存款&流水奖励报表

不修改，沿用现有。
