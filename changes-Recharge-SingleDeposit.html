二、逐项说明

改动 1 · 新增活动条件「单笔充值」新增

规则：周期内每一笔充值成功到账后，按该笔金额匹配达到的最高单档发放 1 笔奖励，不向下叠加；低于最低档不发奖。每笔都发，同一档可重复获得。

与现有条件的区别

对比项首笔充值累计充值单笔充值（新增）
看哪一笔只看周期内第一笔周期内所有充值加总周期内任意一笔
一笔对应几档达到的最高档一笔可一次打满多档达到的最高档，不叠加
周期内可得几次1 次每档 1 次，可叠加由「获奖次数上限」决定（见改动 2）

示例（档位 50→5 / 100→12 / 500→68，每日最多 3 次）：当日依次充值 100、60、30、500 → 第 1 笔得 12、第 2 笔得 5、第 3 笔低于最低档不发奖且不占次数、第 4 笔得 68；次数 3/3 用完，当日后续充值不再发奖。

活动条件顺序

后台单选、活动列表「活动条件」列、PRD 各表格统一调整为：首笔充值 / 单笔充值 / 累计充值 / 连续天数充值。

计入口径

以单个充值订单为单位，订单成功到账才计入，按到账时间归属周期；金额取该订单的到账金额，不含充值返现、活动赠送；未到账 / 失败 / 取消的订单不计入、不占次数。同一会员同时有多笔订单到账时，按到账先后逐笔判定档位与次数。

领取与账变

固定手动领取。点击领取时一次领走当前所有「已产生未领」的奖励，按笔生成多条账变，不支持只领其中某一笔；往期滞留的未领奖励在待领取页领取（见改动 6）。

改动 2 · 新增配置项「获奖次数上限」新增

仅「单笔充值」显示，位于稽核方式与奖励配置之间，文案为「〔周期词〕最多可获奖 [N] 次」，输入框后附说明「（填 0 表示不限制次数，每笔达标充值均赠送）」。周期词随重置方式变化：不重置 = 活动期间、每日、每周。

模式取值规则
不限次数N = 0周期内每一笔达到最低档的充值均赠送，无上限；不存在「次数用完」状态
限次数N = 1~99周期内最多获奖 N 次，用完后后续充值不再产生奖励；周期重置后次数归 0 重新计算

取值与校验

  • 新增时默认填入 0，为空保存时自动恢复 0。
  • 0~99 的整数；小数、负数、超过 99 拦截，提示「获奖次数上限必须为0-99的整数」。

计次口径

  • 每产生 1 笔奖励计 1 次；低于最低档的充值不发奖、不计次数。
  • 限次数模式下，次数在奖励产生时即占用，与是否领取无关；奖励后续被作废（过期作废 / 保留天数作废）不退回次数。
  • 次数按充值日期归属周期：每笔奖励占用的是该笔充值日期（以订单到账成功时间为准）所在周期的次数，与领取日期无关。

例：每日限 3 次、次日领取——1 日充值产生的奖励在 2 日领取，仍计入 1 日的次数，不占用 2 日的次数。跨重置时间点到账的订单计入新周期，例如 23:59 下单、次日 00:01 到账，算次日的次数。

改动 5 · 活动规则说明（系统默认）的联动生成修改

改动 6 · 解除待领取页上线前的临时限制解除

旧版 4.10 因「待领取」跨周期领取入口未上线，对每日 / 每周重置的充值活动做过临时配置限制（UAT 已按此实现，见第四章）。待领取页已上线，充值活动奖励已在其纳入范围内（后台领取方式 = 手动领取且当前可领即进入），跨周期未领的奖励可在待领取页领取，限制前提不再成立，本次全部解除。

首笔 / 单笔 / 累计 + 每日 / 每周
连续天数 + 每周		奖励作废仅可选「过期自动派发 / 过期作废」，两个「保留天数」置灰四项均可选，选保留天数时「奖励领取过期天数」可编辑

仍然保留的限制（属于功能本身的联动，不是临时措施）：单笔充值 / 连续天数充值强制实时领取；次日领取时奖励作废仅「保留天数」两项；连续天数充值无「每日」重置。默认值沿用 4.4 表二：实时领取 → 奖励作废默认「过期自动派发」；次日领取 → 默认「奖励保留天数自动派发」。

解除放开的是前两行组合，它们会产生跨周期滞留的未领奖励——奖励还在有效期内，但主活动页已进入新周期。后两行是原本就能配的组合，处理方式不变。

领取位置（统一规则，不随组合变化）

  • 待领取页：奖励一经产生、进入可领状态，即出现在待领取页，与是否跨周期无关；累计多档的每一档、单笔的每一笔各占一行，支持「全部领取」。直到被领取，或按其「奖励作废」配置自动派发 / 作废后才移除。
  • 主活动页：只展示并只能领取当前周期内产生的奖励——进度与顶部「可领取」金额只计这部分，领取按钮也只领这部分。
  • 周期重置后：主活动页进入新周期，上一周期未领的奖励不再展示、也不能在活动页领取；但它仍在待领取页可领，直至自动派发或作废。
  • 单笔获奖次数不受影响：仍按充值日期所在周期计算，与奖励在哪个周期、哪个页面领取无关（见改动 2）。

例（每日重置 + 保留 3 天）：1 日充值达标产生的奖励保留至 5 日。1 日当天在主活动页和待领取页都能领；2 日起主活动页已是新周期、不再显示这笔奖励，只能在待领取页领；5 日仍未领则按配置自动派发或作废。
