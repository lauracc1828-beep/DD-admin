【H5】待领取奖励失败提示优化

版本：v1.0日期：2026-11-26关联：t105858 待领取奖励提醒优化

一、改动点

入口：优惠 → 待领取（Pendente）

位置改动
一键领取 · 部分成功到账弹框的成功金额下方，增加一行橙色提示
一键领取 · 全部失败不弹到账弹框，点击后显示一条轻提示
待领取列表 · 奖励行一键领取后，领取失败的奖励在该行下方显示红色原因
接口 claimAll · failedItems每条失败返回奖励 ID、原因类型及原因中的配置值

其余列表展示、领取逻辑、到账弹框样式保持不变。

补充说明

  1. 显示时机：点击一键领取后，部分成功时在到账弹框关闭后显示原因；全部失败时与轻提示同时显示。
  2. 消失时机：刷新页面或重新进入待领取页后，原因不再显示。
  3. 一键领取后列表刷新：失败的奖励留在列表中，行下方显示本次返回的原因；已失效的奖励从列表移除。
  4. 原因只显示文字，不带按钮或跳转。一条奖励有多项条件不满足时，按后台配置顺序显示第一项。
  5. VIP 每日、每周、每月奖励，以及受众用户 2 的升级奖励，领取时不校验，不显示原因。
  6. 到账弹框金额是本次实际到账总额；提示中的 {N} 是本次领取失败的奖励数量。

三、页面文字：无法领取原因（列表行下方）

原因类型触发情况中文葡语
VIP_AUDIENCEVIP 升级奖励（受众用户 1），近 N 天内（含当天）无成功充值只需充值一笔，即可领取Basta fazer um depósito para resgatar
FIRST_DEPOSIT申领限制：完成首充可申领请完成首次充值后申领Por favor, conclua seu primeiro depósito para resgatar
DEPOSIT_COUNT申领限制：最近 N 天内充值次数 ≥ N 次请在最近[天数]天内累计充值[次数]次后申领Por favor, conclua [vezes] depósitos nos últimos [dias] dias para resgatar
DEPOSIT_AMOUNT申领限制：最近 N 天内充值金额 ≥ N请在最近[天数]天内累计充值满[金额]后申领Por favor, deposite um total de R$[valor] nos últimos [dias] dias para resgatar
LOGIN_IP申领限制：同登录 IP 只能申领 1 次同一登录IP仅可申领1次Cada IP de login pode resgatar apenas 1 vez
REGISTER_IP申领限制：同注册 IP 只能申领 1 次同一注册IP仅可申领1次Cada IP de cadastro pode resgatar apenas 1 vez
TERMINAL申领终端不符请通过 … 申领Por favor, resgate usando o …
OTHER系统异常（领取时返回）领取失败，请稍后重试Falha na coleta. Tente novamente mais tarde.

占位符替换为后台配置值，金额带货币符号；申领终端「…」沿用现有申领终端提示的终端名称。
