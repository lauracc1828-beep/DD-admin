一、文档说明与范围

本文记录存款页在前台呈现层面的优化点，覆盖 PIX（BESTPAY）与 NewGPay 两个渠道，内容限于文案、底部按钮位置与返回路径三类，不重复描述两个渠道已定稿的业务逻辑。

类别内容章节
页面文案术语统一、区块与字段文案调整、限额提示的呈现方式。第三章
底部按钮主按钮与结算信息由滚动区移至底部固定栏。第四章
返回路径PIX 收银页的返回目标、NewGPay 存款成功后的返回目标。第五章
文案对照两个渠道存款页全部固定展示文案的中葡对照。第六章

不在本文范围：赠送比例及其计算规则——该项属后台配置能力，前台仅按配置值呈现，规则见《新增 NewGPay 支付渠道 PRD》；两个渠道的业务流程与校验顺序，分别见《新增 NewGPay 支付渠道 PRD》与《BESTPAY 收银页站内化 PRD》；页面层级、底部导航与钱包一级页结构，见《钱包页结构调整 PRD》。

三、页面文案调整

钱包页顶部 Tab充值 / 提款存款 / 取款
主按钮立即充值 / 立即提现立即存款 / 立即取款
记录页标题充值记录 / 提款记录存款记录 / 取款记录
收银页失效后按钮重新发起充值重新发起存款

该统一仅作用于前台会员可见文案。后台报表沿用「充值订单记录 / 提现订单记录」等既有命名，两套口径的对应关系见《新增 NewGPay 支付渠道 PRD》第八章。

3.3 限额提示并入输入框

项说明
优化前输入框下方单独一行，文案为「单笔限额 {最低} - {最高}」。
优化后删除该行，限额以纯数字区间作为输入框占位，形如 5-1.000.000（存款）、10-300（取款）。
呈现规则占位中不含「单笔限额」字样与币种单位，单位由输入框左侧前缀（R$ / NGC）给出；数字按客户端语言的千分位规则格式化。
取值来源区间两端取当前渠道的后台限额配置，切换渠道时随之变化。
校验提示不变。金额越界时仍在提交后以轻提示给出完整文案（「最低存款 R$ 5,00」等）。

四、底部按钮固定

项说明
优化前主按钮位于内容区末尾，随页面滚动；「您将收到」位于快捷档位下方。
优化后主按钮与「您将收到」合并到页面底部固定栏，不随内容滚动。

结算栏规格

  1. 结构：自上而下为「您将收到」主行（标签靠左、金额靠右）、「含赠送」副行（仅有赠送时出现）、主按钮。
  2. 与渠道联动：同一 Tab 下两个渠道各有一套结算信息，随渠道切换显隐，同一时刻只展示当前渠道的数值。
  3. 按钮状态：金额为空或为 0 时置灰（不可点击），输入有效金额后激活；提交期间置灰并显示处理中文案以防重复提交。颜色与视觉样式以 UI 设计稿为准。
  4. 与底部导航的共存：钱包为一级页，底部已有常驻导航，两者的叠放规则见《钱包页结构调整 PRD》第五章。

五、返回路径调整

调整两处返回目标，均跳过钱包页直达一级页。

5.1 PIX 收银页的返回

项说明
优化前收银页左上角返回键回到钱包存款页。
优化后左上角返回键直接回到会员进入钱包页之前所在的一级页，跳过钱包页。
目标页判定取会员本次进入钱包页之前停留的那个一级页（首页 / 优惠 / 邀请 / 我的）。
兜底若无法取得来源（如通过外部链接直接进入收银页、或本次会话未访问过其他一级页），回到首页。
订单处理返回不取消订单。该笔待支付订单在其有效期内仍然有效，会员可从存款记录中点回收银页继续支付。
不受影响的入口收银页右上角的记录入口、失效后的「重新发起存款」按钮，仍分别进入存款记录与钱包存款页，不走本规则。

5.2 NewGPay 存款成功后的返回

项说明
优化前提示「存款成功」后停留在存款页，刷新余额。
优化后提示「存款成功」后自动返回会员进入钱包页之前所在的一级页。
触发条件仅在存款成功时触发。失败、余额不足、限额拦截等情形均停留当前页，输入内容保留。
时序先完成扣币与入账、刷新余额并展示成功提示，待提示可被看清后再跳转，不与提示同时发生。
目标页判定与兜底与 5.1 一致。
适用范围仅适用于 NewGPay 这类同步返回结果的渠道。PIX 为扫码后异步到账，提交后进入收银页，不适用本规则。

七、边界与异常处理

编号场景处理方式
7.1收银页返回时来源一级页不可用（已下线、无权限等）按兜底处理，回到首页，不停留在空白页。
7.2NewGPay 存款成功后，自动跳转前会员已手动离开当前页不再执行自动跳转，以会员的手动操作为准。
7.3存款成功提示与自动跳转的时序冲突先展示提示，待提示展示完毕后再跳转；跳转后不重复提示。
7.4切换渠道后限额区间变化，已输入金额越界输入内容保留，占位区间按新渠道更新；提交时按当前渠道限额拦截并提示。
7.5赠送比例为 0「含赠送」副行不渲染，结算栏只有「您将收到」一行，高度随之收缩。
7.6长文案（葡语）导致结算栏主行标签与金额拥挤标签可截断，金额完整展示不截断；金额为关键信息，优先保证其可读性。

八、待确认事项

编号事项说明与影响
8.1术语统一引起的葡语改写「立即存款 / Depositar agora」与「存款成功 / Depósito realizado com sucesso」改自参考平台的 Recarregar 系列用语，需运营确认巴西站更习惯哪一套。若保留 Recarregar，则中文一侧的「存款」与葡语的「充值」语义将不再对齐。
8.2PIX 收银页返回后的找回路径返回跳过钱包页后，会员若想改金额重新下单，需重新进入钱包。是否需要在收银页增加一个「返回存款页」的次级入口，待确认。
8.3取款侧是否同步调整返回路径本次仅调整存款侧。取款提交成功后当前跳转取款记录页，是否也改为返回一级页，待确认。
8.4BESTPAY 存款限额取值现网钱包页标注为 R$ 10,00 - R$ 50.000,00，本文按 R$ 5,00 - R$ 1.000.000,00 呈现，两者不一致，需以后台实际配置为准后更新对照表。
