公告消息 PRD

版本：v1.0作者：Laura更新日期：2026-09-12

本模块位于后台「消息管理 → 公告消息」，用于运营向前台用户投放两类公告：弹窗公告（前台以弹窗形式展示）与公告消息（发送至前台消息中心的收件箱）。配置按「地区 + 商户」维度隔离管理。

一、概述

公告消息模块提供统一的公告投放能力，页面以两个子 Tab 区分两种投放形态：

  • 弹窗公告：用户进入前台时以弹窗形式展示，支持图片型与文字型，支持按弹窗群体、会员层级、优先级与弹窗频率精准控制展示。
  • 公告消息：以站内公告形式发送至前台「消息中心 → 公告」，用户在收件箱内查看，支持按会员层级定向可见。

页面顶部提供筛选项：地区、商户、公告名称，用于按维度检索；配置数据以选定的地区与商户为作用范围。

二、名词与状态定义

公告存在两个相互独立的状态维度，配置与前台展示均须区分：

状态维度定义取值控制方
状态
（启用状态）		表示公告当前是否启用。开启 / 关闭运营手动控制，可随时切换
生效状态表示公告配置变更的落地状态。系统对每次保存执行异步生效处理：定时生效的公告在到达设定生效时间前为「待生效」，到点由系统自动置为「已生效」；立即生效或已生效公告在编辑保存后会有短暂的变更同步过程，期间为「待生效」，同步完成后转为「已生效」。待生效 / 已生效系统按生效方式自动流转

二者相互独立：对已生效的公告执行开启或关闭，仅改变其启用状态，不影响、也不重置其生效状态。

三、后台配置

3.1 列表

弹窗公告列表字段：序号、公告名称、公告类型、公告内容（图片显示缩略图 / 文字显示文本）、弹窗群体、超链接、弹窗优先级、状态（开关，即启用状态）、生效时间、生效状态、操作人、最后修改时间、创建时间、操作（编辑 / 删除）。列表右上角提供「+新增」。

公告消息列表字段：序号、公告名称、公告内容（「点击查看」打开只读详情）、可见层级、发送时间、操作人、操作（删除）。列表右上角提供「公告发放」。公告消息发放后不可编辑，仅支持查看与删除。

3.2 弹窗公告 — 新增 / 编辑

字段含义控件必填输入要求 / 逻辑说明
公告名称公告标识；文字型时作为弹窗顶部标题展示。输入框是为空不可保存，错误提示「请输入公告名称」。
公告状态是否启用（启用状态）。开关是默认开启；与生效状态相互独立（见第二节）。
公告类型公告呈现形态。单选是「文字」/「图片」二选一，切换后表单相应字段联动显示。
选择底图文字型弹窗的背景底图。单选是仅公告类型=文字时显示。「系统默认」使用系统默认底图；「自定义」需上传图片，支持 JPG/PNG/SVG，建议尺寸 700×760；上传后点击缩略图弹出预览大图。
弹窗内容文字型弹窗的正文内容。富文本编辑器是仅公告类型=文字时显示；可内插图片，建议尺寸 700×284，支持 jpg/gif/png。编辑器下方设「取消 / 保存」，内容或所插图片需点击「保存」后方进入右侧预览并视为已保存内容：点击「保存」时内容为空提示「请输入自定义内容」，成功提示「富文本保存成功」；点击「取消」还原至上次已保存内容。整表提交（确定）时若无已保存内容，提示「请上传公告内容」。
上传图片图片型弹窗的整图。上传是仅公告类型=图片时显示；整个弹窗即该图，支持 JPG/PNG/SVG，建议尺寸 700×760；上传后点击图片弹出预览大图。未上传不可保存，错误提示「请上传图片」。
跳转方式点击弹窗后的跳转行为。单选否「内联链接」/「跳转链接」/「无」。选「无」则弹窗不可点击跳转。
跳转类型内联跳转目标。下拉是（内联时）仅跳转方式=内联链接时显示。选项包含：所有启用中的活动；站内页（充值页、推广中心页、提现页、活动页、首页、VIP页、兑换码页、注册页）；Telegram 频道与 WhatsApp——其地址取值自「系统管理 → 系统设置 → 公共资源配置」的 Telegram频道地址 / WhatsApp地址。
跳转链接外部跳转地址。输入框是（外链时）仅跳转方式=跳转链接时显示；填写完整 URL。
弹窗优先级多条弹窗的展示排序权重。数字输入否默认 0；数值越大排序越前。
弹窗方式弹窗的展示频率。下拉是取值见 4.1 弹窗方式说明。
弹窗群体弹窗展示的目标人群。单选是「未登录用户」/「登录用户」。选择「登录用户」时，下方展开「弹窗层级」。
弹窗层级登录用户中可见该弹窗的会员层级范围。多选是（登录用户时）仅弹窗群体=登录用户时显示。提供「全部」及各会员层级（选项取自会员层级配置）；仅勾选层级的用户可见该弹窗。
生效方式公告的生效时机。单选是「立即生效」/「定时生效」。
生效时间定时生效的开始时间。日期时间选择是（定时时）仅生效方式=定时生效时显示；仅设开始时间，须大于当前时间 5 分钟。

3.3 公告消息 — 公告发放

字段含义控件必填输入要求 / 逻辑说明
公告标题收件箱公告的标题。输入框是为空不可发送，错误提示「请输入公告标题」。
公告内容收件箱公告的正文。富文本编辑器是可内插图片，建议宽度 760、高度不限，支持 jpg/gif/png。为空不可发送，错误提示「请输入公告内容」。
可见层级可收到该公告的会员层级范围。多选是提供「全部」及各会员层级（选项取自会员层级配置），勾选「全部」联动全选。

四、前台显示逻辑

4.1 弹窗公告

展示条件：公告须处于启用（状态=开启）且已生效（生效状态=已生效）。命中人群按弹窗群体判定：未登录用户仅对未登录访客展示；登录用户仅对所勾选「弹窗层级」内的会员展示。

弹窗方式（展示频率）：

选项说明
每次登录或访问每次进入网站均弹出，包含未登录访问网站时，以及每次登录成功时。
每日一次每个自然日内对同一用户仅弹出一次。
只弹一次对同一用户仅弹出一次，之后不再弹出。
每回大厅必弹用户每次返回大厅均弹出。

多条合并与排序：当同一时刻有多条弹窗需展示时，合并为一个弹窗、由底部 Tab 切换（Tab 名为公告名称），按弹窗优先级由大到小排序。当展示的公告超过 3 条时，底部 Tab 支持左右滑动，每次最多显示 3 个。

内容形态：图片型整个弹窗为一张图；文字型为底图（系统默认深色底图 / 自定义图）叠加标题与富文本正文，标题与正文居中展示。

用户操作：弹窗底部提供「今日不再提示」，勾选后当天不再弹出；提供关闭按钮；若配置了跳转，点击弹窗按跳转方式跳转（内联至对应站内页 / 活动 / 联系方式，外链跳转至所填 URL）。

4.2 公告消息

命中可见层级的用户在「消息中心 → 公告」Tab（与「支持」「通知」并列）看到公告卡片列表，卡片展示标题与内容摘要；点击卡片进入消息详情，展示标题、发送时间与正文。

七、边界与异常

  • 状态与生效状态独立：关闭已生效公告仅停止其前台展示，不改变生效状态；重新开启后按原生效状态继续展示。
  • 弹窗群体切换：由「登录用户」切回「未登录用户」时隐藏「弹窗层级」；未登录用户不受会员层级限制。
  • 多条弹窗：优先级相同时按创建 / 生效时间兜底排序，合并弹窗内 Tab 顺序与排序一致。
  • 今日不再提示：按用户 + 自然日记录，跨日重置；与「弹窗方式」叠加时，以更严格者为准（如「只弹一次」则不再受当日勾选影响）。
  • 跳转目标失效：内联活动若已下线或站内页不可用，点击不跳转或回落首页（以前台通用兜底为准）。
  • 定时生效：未到生效时间的公告为「待生效」，前台不展示；到点由系统自动切换为「已生效」并开始展示。
  • 公告消息不可编辑：发放后仅支持查看（只读）与删除；如需修改须删除后重新发放。
